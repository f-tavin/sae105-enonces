Étape 0 L'échauffement 15 min, sans internet ni IA

Sur votre propre code :

  1. Passez la galerie des pièces à 3 colonnes. Que devient le bloc vedette ? Reste-t-il des cases vides ? Remettez ensuite 4 colonnes.
  2. Dans la section d'accueil, retrouvez la propriété qui centre verticalement le texte et le visuel, et remplacez sa valeur par flex-start. Notez ce qui change, puis annulez.
Indications
  1. Dans la règle de votre conteneur de galerie, passez grid-template-columns de repeat(4, 1fr) à repeat(3, 1fr). Le bloc vedette garde ses 2 colonnes et 2 rangées : il occupe 4 cases. Les 8 autres blocs remplissent les 8 cases restantes : 4 + 8 = 12 cases, soit exactement 4 rangées de 3. Il ne reste donc aucune case vide.
  2. C'est la propriété align-items: center du conteneur flex de l'accueil (l'élément qui contient le texte et le visuel). Avec flex-start, les deux éléments s'alignent en haut du conteneur : le texte, moins haut que l'image, n'est plus centré verticalement et remonte.

Rappel Les media queries

Une media query applique des règles CSS seulement si une condition est remplie, le plus souvent une largeur d'écran :

/* Ces règles s'appliquent uniquement aux écrans de 767px de large ou moins */
@media (max-width: 767px) {
    .galerie {
        grid-template-columns: 1fr;
    }
}

Trois choses à savoir :

  1. On ne réécrit que ce qui change. Dans une media query, inutile de répéter la couleur de fond des cartes ou leur bordure : elles restent les mêmes. On écrit seulement ce qui doit être différent (le nombre de colonnes, la direction d'un flex, une taille de texte…).
  2. Les media queries se placent à la fin de la feuille de style. En CSS, quand deux règles se contredisent, la dernière l'emporte. Placée au début du fichier, votre media query serait écrasée par les règles normales qui la suivent, et rien ne se passerait.
  3. La balise meta viewport, que vous avez placée à la partie 1, est indispensable. Sans elle, les téléphones affichent la page comme sur un écran d'ordinateur, en tout petit, et les media queries ne se déclenchent pas. Si vous n'avez pas encore cette ligne dans le head de vos fichiers HTML, ajoutez-la : 
    <meta name="viewport" content="width=device-width, initial-scale=1.0">

Le site utilisera deux points de rupture :

Largeur d'écran Appareil Media query
1024 px et plus Ordinateur Aucune : ce sont vos règles normales
de 768 à 1023 px Tablette @media (max-width: 1023px)
767 px et moins Mobile @media (max-width: 767px)

Sur mobile, les deux media queries s'appliquent (767 px est aussi inférieur à 1023 px). Écrivez donc la media query tablette avant la media query mobile : celle-ci n'aura à préciser que ce qui diffère encore de la tablette.

Pour tester : réduisez progressivement la largeur de la fenêtre pour voir les changements se déclencher. Vérifiez ensuite le résultat dans le mode responsive du navigateur (via l'inspecteur) en choisissant un appareil précis : un iPad pour la tablette, un iPhone pour le mobile.

Le test le plus important : sur un mobile, la page ne doit jamais défiler horizontalement. Si c'est le cas, un élément est trop large. Utilisez l'inspecteur pour le trouver : survolez les éléments dans le code et repérez celui qui dépasse.

Étape 3 L'apparence du menu burger 40 min

1. Ajoutez le bouton dans votre en-tête, entre le nom du site et la navigation :

<!-- Bouton burger : visible uniquement en version mobile -->
<button id="burger" class="burger" aria-label="Ouvrir le menu">☰</button>

Le caractère ☰ dessine les trois barres. L'attribut aria-label décrit le bouton aux personnes qui utilisent un lecteur d'écran, puisque le symbole seul ne veut rien dire pour elles.

2. Gérez l'affichage selon l'écran :

  • sur ordinateur, le bouton est masqué (display: none) et le menu reste comme avant ;
  • sur tablette et mobile, le bouton apparaît et le menu est masqué.

3. Préparez le menu ouvert. À la partie 5, un clic sur le bouton ajoutera la classe ouvert au nav. Vous allez donc écrire dès maintenant le style du menu quand il possède cette classe :

.menu.ouvert {
    display: block;
}

Deux classes collées sans espace (.menu.ouvert) désignent un élément qui possède les deux classes à la fois. Avec un espace (.menu .ouvert), ce serait un élément de classe ouvert placé à l'intérieur d'un élément de classe menu : ce n'est pas du tout pareil.

Une fois ouvert, le menu doit s'afficher sous l'en-tête, sur toute la largeur, avec les liens les uns sous les autres et un trait de séparation entre chacun (sauf après le dernier).

Comment tester sans JavaScript ? Ajoutez temporairement la classe à la main dans votre HTML (<nav id="menu" class="menu ouvert">), réglez l'apparence du menu ouvert, puis retirez-la avant de sauvegarder.
